# Primy v14 — Líneas de evaluación

Este documento no constituye una promesa de fechas ni de implementación.

## Candidatos de producto

- Sincronización cloud más transparente y resiliente.
- Dashboard personal de actividad y control responsable.
- Funciones Premium con valor verificable.
- Nuevos juegos y mercados, sujetos a reglas oficiales y validación de dominio.
- Herramientas de análisis histórico con divulgación progresiva.
- Mejoras de observabilidad, rendimiento y pruebas end-to-end.

## Criterio de priorización

Cada propuesta deberá superar la evaluación conjunta de Alex, Yuma, Alvaro y David en valor para el usuario, impacto comercial, complejidad, mantenibilidad, accesibilidad y rigor matemático.
