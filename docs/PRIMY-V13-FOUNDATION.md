# Primy v13 — Experience Foundation

## Product direction

Primy v13 introduces a calm, premium and action-oriented interface. The home screen now has one dominant objective: starting a new play.

## Implemented in this foundation

- Shared v13 button and action-card primitives.
- New focused Home with a single dominant CTA.
- Secondary actions moved into a quieter action area.
- Primy Core branding used only at a meaningful moment.
- Existing generation, saved-play and manual-ticket flows preserved.
- David's uniform mathematical engine remains unchanged.

## Design principles

1. One dominant action per screen.
2. Progressive disclosure instead of dense dashboards.
3. Mobile-first spacing and typography.
4. Commercial, memorable copy without predictive claims.
5. Shared components before page-specific styling.
