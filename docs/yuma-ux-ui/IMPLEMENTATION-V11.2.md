# Yuma UX/UI — Implementazione v11.2

## Migliorie applicate

- Dashboard riscritta con copy orientato ai compiti dell’utente.
- CTA principale adattiva: genera quando non ci sono verifiche, controlla quando esistono giocate pronte.
- Rimosse CTA duplicate dal calendario.
- Distinzione tra “Bote stimato” e “Premio massimo”.
- Etichette temporali più concrete: vendite, sorteggio, risultati disponibili.
- Conferma esplicita prima di registrare una schedina come acquistata.
- Registrazione annullabile dal toast.
- Metriche della giocata riscritte in linguaggio comprensibile.
- Impostazioni tecniche raccolte in una sezione avanzata chiusa di default.
- Badge mobile portati ad almeno 12 px.
- Versione progetto aggiornata a 11.2.0; backup schema 12.

## Principi applicati

- Hick: una CTA dominante in base allo stato.
- Fitts: controlli principali >= 44 px e azioni distruttive/selettive separate.
- Miller: progressive disclosure per dettagli tecnici.
- Jakob: terminologia operativa e pattern familiari.
- WCAG 2.2: target leggibili, feedback reversibile e stato non affidato al solo colore.
