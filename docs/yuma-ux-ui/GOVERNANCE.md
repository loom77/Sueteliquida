# Gobierno UX/UI

Toda modificación visual debe incluir:

- problema de usuario que resuelve;
- flujo afectado;
- estado vacío, carga, error y éxito;
- comportamiento móvil y escritorio;
- revisión de accesibilidad;
- criterios de aceptación observables.

No se aprueban nuevos elementos si duplican una función existente o reducen la claridad de la acción principal.
