# Principios de diseño de Primy

1. Una acción principal por pantalla.
2. Mostrar primero lo necesario para avanzar.
3. Ocultar detalles avanzados hasta que se soliciten.
4. Usar textos claros, directos y no promocionales.
5. Diseñar primero para móvil.
6. Mantener objetivos táctiles de al menos 44 × 44 px.
7. No presentar estadísticas como promesas.
8. Garantizar contraste, foco visible y navegación por teclado.
