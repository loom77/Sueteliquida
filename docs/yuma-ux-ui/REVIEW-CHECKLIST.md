# Lista de revisión UX/UI

- [ ] El usuario entiende qué hacer primero.
- [ ] La pantalla tiene una jerarquía visual clara.
- [ ] El contenido secundario no compite con la acción principal.
- [ ] Los textos están en español correcto.
- [ ] Los controles tienen etiquetas accesibles.
- [ ] El foco y el teclado funcionan.
- [ ] Los estados vacío, carga, error y éxito están definidos.
- [ ] La vista funciona desde 320 px.
- [ ] Se cumplen los criterios WCAG 2.2 AA aplicables.
