# Iker Visual Restyle — Primy v12.5

## Dirección visual

Primy adopta una identidad de lotería contemporánea, luminosa y responsable. La Primitiva utiliza verde profundo, mint, crema y acentos dorados; EuroDreams conserva un universo violeta diferenciado.

## Tipografía

- Sora 600/700: títulos, cifras y bolas.
- Inter 400/500/600/700: interfaz, formularios y textos.

## Componentes actualizados

- AuthScreen
- AppShell
- DashboardView
- GenerateView / GeneratorPanel
- TicketPreview / TicketUI
- PlaysView / TicketHistory
- Diálogos, estados y ajustes mediante los nuevos tokens

## Accesibilidad

- Contraste mantenido en botones y texto.
- Estados con icono y color.
- Objetivos táctiles de 44–48 px.
- Animaciones desactivadas con `prefers-reduced-motion`.
