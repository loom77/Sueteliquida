# Primy v16.8.1 — Winning Match Visual System

## Objetivo
Hacer inequívoca la correspondencia entre los números del boleto y el resultado oficial.

## Jerarquía visual
1. Coincidencia: color del juego, texto blanco, aro dorado y check.
2. Número oficial sin coincidencia: bola de resultado con borde reforzado.
3. Número del boleto sin coincidencia: atenuado después de comprobar.

## Cobertura
- La Primitiva
- Bonoloto
- Euromillones
- El Gordo de la Primitiva
- EuroDreams
- Elementos adicionales: estrellas, complementario, reintegro, clave y Sueño.

## Accesibilidad
La coincidencia no depende únicamente del color: incorpora check visible, contraste reforzado y etiqueta accesible. Las animaciones respetan `prefers-reduced-motion`.
