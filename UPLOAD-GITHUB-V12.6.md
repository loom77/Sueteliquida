# Subir Primy v12.6 a GitHub

1. Descomprime `primy-v12.6-visual-polish-mascot-system-github.zip`.
2. Abre la carpeta descomprimida.
3. Sube todos los archivos y carpetas interiores a la raíz de `loom77/Sueteliquida`.
4. Sustituye los archivos existentes.
5. Confirma directamente en `main` con el mensaje: `Primy v12.6 — Visual polish y sistema mascota`.
6. Espera a que Vercel muestre el despliegue como `Ready`.
7. Recarga la app con `Command + Shift + R`.
