# Validación de reglas — Primy v12.2

## La Primitiva

- Seis números por apuesta simple.
- Un único Reintegro para todo el resguardo.
- El premio de Reintegro se aplica una sola vez al importe total jugado.
- Máximo de ocho apuestas simples por boleto.

## EuroDreams

- Seis números y un número Sueño por apuesta simple.
- Cada apuesta puede conservar su propio número Sueño.
- Máximo de seis apuestas simples por boleto.

Primy genera apuestas simples separadas. Las apuestas múltiples combinatorias no se presentan como una función disponible.
