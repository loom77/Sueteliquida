# Subir Primy v12.5 a GitHub

1. Descomprime `primy-v12.5-iker-visual-restyle-github.zip`.
2. Abre la carpeta extraída.
3. En el repositorio `loom77/Sueteliquida`, selecciona **Add file → Upload files**.
4. Sube todo el contenido interno de la carpeta. No subas el ZIP cerrado ni una carpeta contenedora adicional.
5. Confirma el commit directamente en `main` con el mensaje: `Primy v12.5 — Iker Visual Restyle`.
6. Espera a que Vercel muestre el deployment como **Ready**.
7. Abre Primy en una ventana de incógnito para validar la versión nueva y después elimina la caché de la PWA anterior si fuera necesario.

Variables de Vercel requeridas:

- `LOTERIA_API_KEY`
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
